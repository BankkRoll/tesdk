# Examples

> Four runnable applications and 45 focused snippets, all typechecked in CI
> against the built SDK.

## Applications

- [Node CLI](https://github.com/BankkRoll/tesdk/tree/main/examples/node-cli): Browser OAuth with a loopback server, file-backed tokens, wake handling
- [Next.js 16](https://github.com/BankkRoll/tesdk/tree/main/examples/nextjs-app): Server Actions, httpOnly cookie sessions, streaming with Suspense
- [Vite SPA](https://github.com/BankkRoll/tesdk/tree/main/examples/vite-spa): PKCE in the browser, and the dev proxy Tesla's missing CORS headers force
- [Cloudflare Worker](https://github.com/BankkRoll/tesdk/tree/main/examples/cloudflare-worker): Cron fleet monitor, KV token store, zero Node built-ins
